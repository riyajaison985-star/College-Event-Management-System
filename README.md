# College Event Management System

A Java-based academic project developed using Object-Oriented Programming, JDBC, MySQL and Maven.

## Project Overview

The College Event Management System helps verified college students view and register for college events. Organizers can manage event information and view participants.

## Technologies Used

- Java 17
- Object-Oriented Programming (OOP)
- JDBC
- MySQL
- Maven

## Features

- Student registration and login
- College ID verification
- View available events
- Register for events
- Check event availability
- Organizer login
- Event management
- Database-backed record storage

## OOP Concepts

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Database

The project uses MySQL for storing student, organizer, event and registration information.

Run the SQL script in MySQL Workbench to create the database and tables.

## How to Run

1. Install Java 17.
2. Install MySQL Server.
3. Create the project database using `database.sql`.
4. Open the project in IntelliJ IDEA.
5. Load the Maven dependencies.
6. Configure your local database credentials.
7. Run `Main.java`.
